# Revised dashboard demonstration

Practice from Reset. These are demonstration steps, not a completed peer-feedback log. Exact public deployment and screenshots should be checked after approval.

## 1. Start with the question

"A small footbridge and a large crossing each count as one structure, but contribute very different amounts of deck area. I wanted to see whether the condition picture changes when I use those two measures."

Show 813 structures. Compare the solid count bars with the hatched area bars on their common scale. Explain that Closed is a separate status. These are reported conditions in a dated inventory, not a live safety assessment.

## 2. Select Fair and Poor, then Manhattan

Select Fair and Poor. The headline becomes 526 records, but Good and Very good retain their original condition-chart values in gray. The condition chart preserves all conditions while other filters apply.

Select Manhattan. The headline becomes 138, but the borough chart still compares the 526 Fair/Poor structures across all boroughs. Manhattan remains about 26.2%, not 100%. The condition chart now compares all 189 Manhattan records and highlights Fair/Poor within them.

Hover a borough row. Explain that the light reference markers show that borough's count and area shares of the full 813-record inventory. The tooltip difference is in percentage points. This comparison does not show the percentage of a borough's own inventory that is Fair or Poor.

## 3. Show medians, not just individual points

Reset. The third view places area on a logarithmic horizontal axis: equal steps mean tenfold area increases. Condition defines the rows, shape defines the bridge-code group, and marker area represents a span band. A span is a section between neighboring supports.

Point to the median table. For Fair, PED-coded n = 103 has median area 1,500 sq ft and median spans 3; other codes n = 415 has median area 6,517 sq ft and median spans 2. Explain why both area and spans matter. The table uses exact values rather than estimating from point sizes. Do not generalize from the two PED-coded Poor records.

## 4. Demonstrate each dropdown

- Choose Manhattan from the Borough dropdown, then clear its chip. Explain that this is the same borough selection as clicking the chart; the borough comparison still retains other rows.
- Choose PED-coded in Bridge group: 133 records. The other group's median cells show no records rather than zero medians. Clear the chip to compare both groups again.
- Choose Legacy exception in Rating basis: 11 records. Explain that this is the report's explicit exception list, not every old inspection. Clear the chip. If time permits, show NBI-W: 802 records.
- Enter 100000 for minimum deck area: 28 records. Clear it before the next step.

## 5. Search and inspect an older record

Search BIN 2232120. Hover the point to show the expanded PED-A components, inspection year 2019 and full recorded date. Click it to pin source details. Explain that a 2024 report can contain earlier inspection dates. This record is not in the legacy-exception list. Reset.

## 6. Box selection and recovery

Start a drag from blank space clearly inside the individual plot, not from a point or axis label. Draw a box around a group. Show the structure-selection chip, selected total and median table updating. The result depends on the box bounds; do not promise a fixed count. Use Clear structure selection to recover the eligible points, then Reset to 813.

## 7. Show the data explanation

Open About the data and its limits. Point out the original report, 2017-2024 inspection dates, legacy exceptions and area-sum discrepancy. Show the code glossary: PED Pedestrian, A Arterial, R Ramp, O Off-System; NBI-W National Bridge Inventory Weighted.

Finish by inviting an open question: "Try a condition or group of your choice. Is it clear what each percentage is a share of?" Record actual feedback separately, with the person's name, issue and planned change. Do not treat this practice script as evidence of a completed session.
